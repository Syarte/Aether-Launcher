# Windows: особенности, о которые спотыкаются лаунчеры

Основная платформа проекта. Здесь собрано то, что на других ОС либо
не встречается, либо ведёт себя иначе.

## Пути

**Предел длины пути.** Локальный Maven-репозиторий даёт глубокую вложенность,
а Forge добавляет артефакты с длинными классификаторами. Вместе с путём вида
`C:\Users\<длинное имя>\AppData\Roaming\Aether\game\libraries\...` легко
выйти за 260 символов, после чего процессоры инсталлятора падают с невнятной
ошибкой ввода-вывода. Меры: держать каталог данных коротким, использовать
NIO (`java.nio.file`), который умеет длинные пути, и при установке
предупреждать, если целевой каталог уже длиннее ~120 символов.

**Кириллица в имени пользователя.** Классика: путь `C:\Users\Пользователь\...`
ломает часть процессоров Forge и старые версии LWJGL. Проверять кодировку
пути на старте и предлагать сменить каталог установки — дешевле, чем потом
разбирать баг-репорты.

**OneDrive.** `AppData\Roaming` иногда попадает под синхронизацию.
Каталог игры туда класть нельзя: синхронизация тысяч мелких файлов ассетов
подвешивает машину. Стоит проверять, не находится ли выбранный путь
под управлением OneDrive.

## Антивирусы и SmartScreen

Неподписанный exe получает предупреждение SmartScreen, и его репутация
набирается месяцами. Для публичного релиза нужен сертификат подписи кода —
OV дешевле, но репутацию всё равно набирает; EV даёт доверие сразу.
Подписывать нужно и MSI, и вложенный exe.

Отдельная проблема: лаунчер запускает дочерний JVM-процесс с длинной
командной строкой и качает исполняемые файлы — эвристики некоторых
антивирусов реагируют. Помогает подпись и отсутствие самораспаковки
во временные каталоги.

## Java и JVM

- Рантайм Mojang для `windows-x64` распаковывается в
  `runtimes/<component>/windows-x64/bin/java.exe`. Символические ссылки
  из манифеста на Windows требуют прав или режима разработчика — код
  оборачивает их в `runCatching`, на Windows они обычно и не встречаются.
- Для запуска без консольного окна нужен `javaw.exe`, а не `java.exe`.
  Сейчас используется `java.exe`, чтобы читать вывод игры в журнал; если
  журнал не нужен, стоит переключаться на `javaw`.
- `-Dos.name=Windows 10` в аргументах — не костыль ради обхода, а известное
  требование: старые версии LWJGL некорректно определяют Windows 11.

## Установка

`perUserInstall = true` в конфигурации jpackage ставит приложение
в профиль пользователя без прав администратора. Это заметно снижает трение
при установке и нужно для будущего автообновления: обновлять
per-user установку можно без UAC-запроса.

## Хранение токенов

Ключ шифрования обёрнут в DPAPI (`CryptProtectData`, пользовательская
область). Файлы, скопированные на другую машину или прочитанные другим
пользователем Windows, бесполезны. На macOS и Linux эквивалент пока
не реализован — там защищают только права доступа, и это честно отражено
в `SecretProtection.isHardened`.

## Что проверить на реальной машине

1. Запуск версии 1.21+ (современный формат аргументов, natives в classpath).
2. Запуск 1.12.2 (legacy `minecraftArguments`, распаковка natives в каталог).
3. Установка Forge на 1.20.1 — самый нагруженный процессорами случай.
4. Установка NeoForge на 1.21.1.
5. Учётная запись Windows с кириллицей в имени.
6. Машина с 8 ГБ RAM: верхняя граница слайдера должна быть адекватной.
